## SMART 3D v1.3

**English** · 한국어는 아래에 있어요

### Download
| File | Description |
|---|---|
| **SMART3D_EN_v1.3.exe** | English Windows executable — double-click to run, no installation |
| **SMART-3D_EN_v1.3_html.zip** | English HTML version (Chrome / Edge) + picture help |

On first run, if Windows shows “Windows protected your PC”, click **More info → Run anyway**.

### What’s new
- **AI Render 1.3 — node graph** (F10) — connect view capture · GI render · loaded images · image to edit · view capture video · reference video · material / mood / object / person references · prompt · image and video generators on a node canvas. Every run adds a result node; the right panel holds the AI connection, the results gallery with **A / B compare** and the save folder. Short prompts get the photographic AI Render direction automatically. The classic panel is still there.
- **◉ Capture** on the timeline — records the current view at a set ratio and frame count while you orbit / zoom: a video source for the video generator.
- **Auto Dim** (Views ▸ Auto Dim) — CAD-style dimensions on 3D objects: overall sizes, big steps, holes (n-Ø, centre lines), rounds (n-R), placed next to the edge they measure; edit · delete · move · 2-point / edge / Ø / angle tools; PNG / PDF.
- **Drawing sheet** (📐 Drawing) — drag a front view, drag out aligned projected views (KS 3rd angle · 1st angle), hidden lines, centre lines, automatic isometric view with key outer sizes, right-click → “Create dimensions?”, end-point snapping.
- **Build on surfaces (AutoGrid)** — create objects, shapes and lines right on a face, aligned to its normal; empty space uses the grid as before.
- **Boolean cleanup** — no split lines or stray points on faces cut by a boolean.

### 새 기능
- **AI Render 1.3 — 노드 그래프**(F10) — 뷰 캡처 · GI 렌더 · 불러온 이미지 · 수정할 이미지 · 뷰 캡처 영상 · 참고 영상 · 참고 재질 / 분위기 / 오브젝트 / 인물 · 프롬프트 · 이미지 / 영상 생성 노드를 캔버스에서 연결. 생성할 때마다 결과 노드가 생기고, 오른쪽에서 AI 연결 · 생성 결과 **A / B 비교** · 저장 폴더를 다뤄요. 짧은 프롬프트도 AI Render 사진 연출로 자동 보강. 클래식 패널도 그대로 있어요.
- 타임라인 **◉ 캡처** — 정해진 비율 · 프레임으로 지금 뷰를 녹화, 녹화 중 뷰를 돌리고 확대 · 축소한 움직임이 영상 생성의 소스가 돼요.
- **Auto Dim**(Views ▸ Auto Dim) — 3D 물체에 CAD식 치수: 전체 크기 · 큰 단차 · 구멍(n-Ø, 중심선) · 곡면(n-R), 재는 모서리 가까이에 배치. 수정 · 삭제 · 이동 · 2점 / Edge / Ø / 각도 도구, PNG / PDF.
- **도면 시트**(📐 도면) — 드래그로 정면도, 끌어내서 정렬된 투상도(KS 3각법 · 1각법), 숨은선 · 중심선, 외형 치수가 붙은 등각 투상도 자동 생성, 우클릭 → “치수를 생성할까요?”, 끝점 스냅.
- **표면에 맞춰 만들기(AutoGrid)** — 물체 · 도형 · Line을 면 위에 그 노멀 방향으로 바로 만들어요. 빈 곳은 기존처럼 그리드에.
- **Boolean 정리** — 불리언으로 잘린 면에 분할선 · 불필요한 점이 보이지 않아요.
