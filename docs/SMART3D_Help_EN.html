1Screen layout

  • ① Menu — open · save · export files, Animation, Render (AI Render)
  • ② Toolbar — select · move · rotate · scale, axis lock, snaps, mirror, layers, materials, AI
  • ③ Viewport — wheel = zoom · middle-drag = pan · Alt+middle-drag = orbit. Top-right buttons change the view and shading; right-click = View Menu
  • ④ Command panel — Create · Modify · Hierarchy · Display · SMART Utils
  • ⑤ Timeline — make animation keys and play them
  • ⑥ Status bar — selection info, X · Y · Z input, navigation tools

2Create · move objects

  • Pick Box, Sphere… in the Create tab and drag in the viewport. Shapes = lines (splines), Cameras = cameras
  • Q select · W move · E rotate · R scale. Lock an axis with X / Y / Z / XY on the toolbar or F5–F8
  • S = snap. Type numbers in the X · Y · Z fields of the status bar for exact positions
  • Ctrl+Z undo · Ctrl+Y redo · Delete removes

3Copy (Shift+drag)

  • With Move (W), hold Shift and drag the gizmo to copy
  • On release the Copy options open — Fill between: fill the gap between original and copy evenly / More at same spacing: keep going past the copy
  • Change the count by typing, ＋/− or the wheel; it previews live. Enter = OK · Esc = just 1
  • Ctrl+V = copy in place

4Editing — Modify Poly · Spline

  • Select an object and use Modifiers ▸ Convert to Modify Poly (lines: Modify Spline)
  • In the Modify tab, keys 1–5 pick vertex · edge · border · polygon · element
  • Extrude · Inset · Bevel · Chamfer · Bridge · Connect… are panel buttons (assign keys in Settings ▸ Hotkey Editor)
  • Shift+drag polygons or edges to extrude right away

5Modifiers

  • Add them with ＋ Add Modifier… in the Modify tab or the Modifiers menu — they stack on top and keep the original
  • Multi Select — select vertices · edges · faces inside a spline or 3D object (Feather softens it)
  • Projection Spline — imprint a line on a 3D object and delete inside/outside or side A/B
  • Pick an item in the stack to see its settings. Bulb = on/off

6SMART Utils — Drop Surface

  • SMART Utils tab ▸ Pick Surface — choose the ground object
  • Select the objects or splines to drop and press Drop Surface
  • Axis (Z/X/Y) · Flip, Contact (first touching point) / Pivot, align to slope, conform splines point by point

7Material Editor (M)

  • Open with M, make one with ＋ New Material, then set color and texture
  • Click Apply to selection, or drag the material onto an object in the viewport
  • Mapping ▸ Random = different mapping per element · Color correct = random hue · saturation · brightness

8Camera · Safe Frame

  • Create ▸ Cameras — pick the Interior / Exterior / Product preset and drag to place
  • C = camera view (navigating there moves the camera)
  • Shift+F = Safe Frame ratio. AI Render and video export use the same ratio

9Animation timeline

  • Turn on ● REC, move to a frame and change objects or parameters — keys are made automatically. Or K = add key
  • Space play/stop · , . one frame · Shift+, . previous/next key
  • Drag on empty space to select keys → Delete removes them · drag a key = move (Alt = copy) · right-click = interpolation
  • Animation menu ▸ export video · PNG sequence, RAM preview, GLB (with animation)

10AI Render — image (F10)

  • Pick a provider under AI connection — Google (key) · Higgsfield API (key) · Higgsfield Login (in SMART3D.exe)
  • Generate: image model · resolution · preset · sky · extra instructions · reference images → Generate AI
  • Result: before/after slider, overlay on the viewport, auto-save to a folder

11AI Render — video

  • Click 🎬 Video at the top for video mode — the provider’s video models (Veo, Higgsfield models) load automatically
  • Source: current view / AI image / animation (first · last frame + captured clip as reference)
  • Length and resolution show only what the model supports. Describe the camera move in Motion direction
  • Use “Last frame → continue” on a result to chain the next shot

12Save · export

  • File ▸ Save to Browser (Ctrl+S). Work is auto-saved; bring it back with Restore last action
  • File ▸ Export GLB · FBX · OBJ · STL; Import is in the same menu
  • GLB includes the move · rotate · scale animation
