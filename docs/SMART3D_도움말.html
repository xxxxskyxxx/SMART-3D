1화면 구성

  • ① 메뉴 — 파일 열기·저장·내보내기, Animation, Render(AI Render)
  • ② 툴바 — 선택·이동·회전·크기, 축 고정, 스냅, 미러, 레이어, 재질, AI
  • ③ 뷰포트 — 휠 = 확대/축소 · 가운데 버튼 드래그 = 이동 · Alt+가운데 드래그 = 회전. 오른쪽 위 버튼으로 뷰와 표시 방식, 우클릭 = View Menu
  • ④ 명령 패널 — Create · Modify · Hierarchy · Display · SMART Utils
  • ⑤ 타임라인 — 애니메이션 키 만들기와 재생
  • ⑥ 상태 표시줄 — 선택 정보, X·Y·Z 좌표 입력, 화면 이동 도구

2물체 만들기 · 이동

  • Create 탭에서 Box·Sphere 등을 고르고 뷰포트에서 드래그해서 만들어요. Shapes = 선(스플라인), Cameras = 카메라
  • Q 선택 · W 이동 · E 회전 · R 크기. 툴바 X / Y / Z / XY 또는 F5~F8로 축을 고정해요
  • S = 스냅. 상태 표시줄 X·Y·Z 칸에 숫자를 넣으면 정확한 위치로 옮겨져요
  • Ctrl+Z 되돌리기 · Ctrl+Y 다시 하기 · Delete 지우기

3복사 (Shift+드래그)

  • 이동(W) 상태에서 Shift를 누른 채 기즈모를 드래그하면 복사돼요
  • 놓으면 복사 옵션 창이 떠요 — 사이에 채우기: 원본과 복사본 사이를 같은 간격으로 채움 / 같은 간격으로 더: 복사본 뒤로 계속
  • 개수는 입력·＋/−·휠로 바꾸고 바로 미리 보여요. Enter = 확인 · Esc = 1개만
  • Ctrl+V = 그 자리에 복사

4편집 — Modify Poly · Spline

  • 물체를 선택하고 Modifiers ▸ Convert to Modify Poly (선은 Modify Spline)
  • Modify 탭에서 1~5 키로 점 · 엣지 · 테두리 · 면 · 요소를 골라 편집해요
  • Extrude · Inset · Bevel · Chamfer · Bridge · Connect 등은 패널 버튼으로 (Settings ▸ Hotkey Editor로 단축키 지정 가능)
  • 면/엣지를 Shift+드래그하면 바로 뽑아내기

5모디파이어

  • Modify 탭의 ＋ Add Modifier… 또는 Modifiers 메뉴에서 추가해요 — 원본은 그대로 두고 위에 쌓여요
  • Multi Select — 스플라인·3D 물체로 영역을 골라 점·엣지·면 선택 (Feather로 부드럽게)
  • Projection Spline — 선을 3D 물체에 새기고 안쪽/바깥쪽 또는 A/B 한쪽을 지우기
  • 스택에서 항목을 고르면 그 단계의 설정이 보여요. 전구 = 켜기/끄기

6SMART Utils — Drop Surface

  • SMART Utils 탭 ▸ Pick Surface로 바닥이 될 물체를 고르기
  • 내려놓을 물체·스플라인을 선택하고 Drop Surface
  • Axis(Z/X/Y)·Flip, Contact(닿는 점)/Pivot, 기울기에 맞춰 회전, 스플라인은 점마다 붙이기

7재질 편집기 (M)

  • M으로 열고 ＋ 새 재질로 만든 뒤 색과 텍스처를 정해요
  • 선택에 적용을 누르거나, 재질을 뷰포트의 물체 위로 끌어다 놓으면 적용돼요
  • Mapping ▸ Random = 요소마다 다른 매핑 · Color correct = 색상·채도·밝기 무작위 변화

8카메라 · Safe Frame

  • Create ▸ Cameras — 실내/실외/제품 프리셋을 고르고 드래그해서 만들어요
  • C = 카메라 뷰 (카메라에서 보며 이동·회전하면 카메라가 움직여요)
  • Shift+F = Safe Frame 비율. AI Render와 영상 내보내기가 이 비율을 그대로 써요

9애니메이션 타임라인

  • ● REC를 켜고 프레임을 옮긴 뒤 물체·파라미터를 바꾸면 자동으로 키가 생겨요. 또는 K = 키 추가
  • Space 재생/정지 · , . 한 프레임 · Shift+, . 이전/다음 키
  • 빈 곳을 드래그해 키 여러 개 선택 → Delete로 지우기 · 키 드래그 = 이동(Alt = 복사) · 우클릭 = 보간
  • Animation 메뉴 ▸ 영상 · PNG 시퀀스 내보내기, RAM 미리보기, GLB(애니메이션 포함)

10AI Render — 이미지 (F10)

  • AI 연결에서 제공자를 골라요 — Google(키) · Higgsfield API(키) · Higgsfield 로그인(SMART3D.exe에서)
  • 생성: 이미지 모델 · 해상도 · 프리셋 · 하늘 · 추가 지시 · 참고 이미지 → Generate AI
  • 결과: 슬라이더로 전/후 비교, 뷰포트에 겹쳐 보기, 저장 폴더 자동 저장

11AI Render — 영상

  • 맨 위 🎬 영상을 누르면 영상 모드 — 제공자에 맞는 영상 모델(Veo, Higgsfield 모델)이 자동으로 나와요
  • 소스: 현재 뷰 / AI 이미지 / 애니메이션(첫·끝 프레임 + 캡처 영상을 참고로)
  • 길이·해상도는 모델이 지원하는 값만 보여요. 움직임 지시에 카메라 동작을 적어요
  • 결과의 “끝 프레임 → 이어 만들기”로 다음 컷을 이어서 만들 수 있어요

12저장 · 내보내기

  • File ▸ Save to Browser (Ctrl+S). 작업은 자동 저장되고, 마지막 작업 복구로 되살릴 수 있어요
  • File ▸ Export GLB · FBX · OBJ · STL, Import도 같은 메뉴
  • GLB에는 이동·회전·크기 애니메이션이 함께 들어가요
